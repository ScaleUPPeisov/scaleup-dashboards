# Регрессионная проверка VYRON APEX

Состояние: проверка продолжается. Последний ранее подтверждённый общий прогон JavaScript: 1 312 успешно и один opt-in тест пропущен; этот результат относится к прежнему срезу кода. Проверка новых изменений проводится отдельно.

`FUNCTIONAL_PARITY_MATRIX.md` и структурное сопоставление JSX фиксируют покрытие и вопросы; автоматическое совпадение узлов не доказывает функциональное соответствие. Ни одна строка не получила PASS без фактической проверки. В частности, выбор количества видео для каждого канала в массовой публикации требует реализации или подтверждения существующего пользовательского маршрута.

Полная проверка восстановления загрузок, пользовательских операций, всех IPC, SQLite, доступности и работы при переключении разделов не завершена. Реальные публикации и изменение данных каналов не выполнялись.
