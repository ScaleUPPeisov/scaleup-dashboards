VYRON APEX — тестовый браузерный пакет
Распакуйте ZIP. Запустите START_PREVIEW.command либо из Терминала:
cd "/путь/к/распакованной/папке"
python3 scripts/apex_interactive_preview.py --prebuilt

Нужен Python 3; Node.js, Rust и npm не нужны.
Откроется локальный браузер 127.0.0.1 на случайном порту.
33 синтетических канала, реальные операции и IPC запрещены по умолчанию.
Это не установщик, не native release и не подтверждение изоляции WKWebView.
Для остановки нажмите Ctrl+C. Не используйте реальные авторизации или материалы.
REVISION.txt содержит точный коммит исходников.
