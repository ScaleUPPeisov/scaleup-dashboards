# VYRON Studio Draft Bridge 2.0.2

Локальный bridge для видимых строк YouTube Studio → VYRON.

1. Chrome → `chrome://extensions`.
2. Включить «Режим разработчика».
3. «Загрузить распакованное расширение» и выбрать эту папку.
4. Открыть YouTube Studio → Контент.
5. VYRON должен быть запущен. Bridge работает только через `127.0.0.1:19470`.

Расширение не читает cookies, OAuth-токены и не вызывает скрытые YouTube Studio API.
