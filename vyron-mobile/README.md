# VYRON Mobile

Design-locked iPhone control center for VYRON / ENDLUME.

## Design source of truth
- Dark graphite background only
- Electric blue / violet brand accent
- Premium analytics cards
- Bottom nav: Главная / Каналы / Проекты / Аналитика / Настройки
- iPhone 14 Pro target: 393×852 pt
- No Material UI, no light theme, no tables, no redesign

## Run
```bash
cd vyron-mobile
npm install
npm run ios
```

Current build is UI-complete with demo data. Desktop sync/API is intentionally isolated from UI and will be wired separately.
