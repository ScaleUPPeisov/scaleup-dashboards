# VYRON 0.6.1 — Metadata Hub

- Новый отдельный раздел «Метаданные» в боковом меню.
- Прямая вставка 30–50 комплектов title / description / tags / date из ChatGPT без промежуточного файла.
- Поддержка JSON / TXT / CSV сохранена.
- Два режима применения: будущие проекты VYRON и уже загруженные private/scheduled видео YouTube.
- Для будущих проектов metadata сохраняется в VideoJob и metadata.json проекта; final.mp4 наследует её при публикации.
- Для уже загруженных роликов VYRON подтягивает private/scheduled видео, показывает сопоставление и обновляет metadata через YouTube API.
- Public-видео намеренно исключены из массового применения.
- Предпросмотр показывает, сколько строк сопоставлено и какие VIDEO_XXX не найдены.
