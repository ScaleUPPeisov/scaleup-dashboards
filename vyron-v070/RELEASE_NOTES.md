# VYRON 0.7.0 — Premium Compact UI

Visual redesign built on VYRON 0.6.1.

## Changed
- Premium compact macOS dark UI.
- Smaller 32–34 px action buttons with restrained hover states.
- More compact sidebar, top bar, cards, toolbars and inputs.
- Cleaner SF Pro/system typography and improved hierarchy.
- Denser Existing YouTube video list while keeping thumbnails and expand/edit mode.
- More compact Metadata Hub, analytics dashboard and competitor cards.
- Reduced decorative blur/glow/shadows for smoother rendering.
- Responsive density improvements for MacBook-sized windows.

## Functional safety
This release intentionally does not change YouTube OAuth, YouTube API/Tauri commands, application state schema, metadata parsing logic, analytics requests, competitor refresh logic, autopilot or publishing business logic. UI text changes do not replace or remove event handlers.
