# VYRON 0.8.1

## Existing Videos — chronological control

- Added independent list sorting by scheduled/published date.
- `Дата ↑` shows videos in chronological order so the publication chain is immediately visible.
- `Дата ↓` shows the latest scheduled dates first.
- Added YouTube oldest/newest display modes and `Private first`.
- Display sorting does not change the scheduling algorithm or mutate YouTube metadata.
- Duplicate date/time slots are highlighted with `⚠ Совпадает дата`.
- Existing OAuth, sync, metadata, scheduling, bulk update, undo and thumbnail behavior is preserved.
