# VYRON YT PEISOV 2.0.12 — Production Materials & Project Cleanup

## Image Folder Import
- В `Производство → Материалы → Изображения` сохранён существующий сбор через `НАЧАТЬ СБОР` из `~/Downloads`.
- Добавлена отдельная кнопка `ИМПОРТ ИЗ ПАПКИ` для выбора любой папки на Mac.
- Импорт рекурсивно собирает `jpg / jpeg / png / webp` и привязывает изображения к текущему каналу.
- Проекты заранее создавать не нужно: изображения сохраняются в persistent image pool канала и используются при последующей сборке.
- Несколько папок можно импортировать последовательно; нумерация продолжается, повторный импорт того же source path не создаёт дубль.
- Исходные файлы не перемещаются и не удаляются — VYRON хранит собственные копии в Production Manager storage.
- Повторный запуск Downloads Collector продолжает существующий image pool вместо его сброса.

## Удаление всех проектов
- В истории Production добавлена кнопка `УДАЛИТЬ ВСЕ ПРОЕКТЫ`.
- После явного подтверждения VYRON удаляет все VIDEO-проекты текущего канала во всех его batch через штатный безопасный batch-delete.
- Связанные локальные VIDEO jobs очищаются.
- Импортированные изображения, image pool, музыкальная библиотека и настройки канала сохраняются.

## Channel Status
- Статус канала разделён на локальный/API-статус без дополнительных YouTube-запросов.
- Локальные ошибки можно открыть для просмотра деталей.

## Совместимость и регрессии
- Shorts Factory из 2.0.11 сохранён; проверка расписания использует существующие `todayKrasnoyarskDate` и `shortsScheduleSlots`.
- Добавлены regression-тесты рекурсивного импорта, persistence без проектов, duplicate-safe повторного импорта, накопления нескольких папок и полного удаления проектов без потери изображений/музыки.
- Publisher, OAuth, YouTube upload/recovery, security core и остальные защищённые подсистемы не менялись.
